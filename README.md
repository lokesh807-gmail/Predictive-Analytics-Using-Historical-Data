# Predictive Analytics Using Historical Data

## 📌 Project Overview

This project focuses on using historical sales data to build a predictive model for forecasting future sales trends.

The project uses Linear Regression with time and seasonal features to learn patterns from historical monthly sales data and predict future sales.

This project was completed as part of the **Thiranex Data Analytics Internship – Task 3**.

---

## 🎯 Objective

The main objectives of this project are:

- Analyze historical sales data
- Clean and preprocess the dataset
- Identify sales trends and seasonal patterns
- Build a predictive model
- Evaluate model performance
- Compare actual and predicted sales
- Forecast future sales

---

## 📊 Dataset

The dataset contains **48 months of historical sales data** from January 2022 to December 2025.

### Dataset Columns

| Column | Description |
|---|---|
| Date | Monthly sales date |
| Sales | Monthly sales amount |
| Orders | Number of orders |
| Customers | Number of customers |
| AverageOrderValue | Average value per order |

### Data Source

The dataset is **synthetic data created for educational and internship purposes**, as a dataset was not provided by Thiranex.
